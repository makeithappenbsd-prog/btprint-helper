# btprint-helper

Label printer helper for the Bedikas Tefilin app (Windows).

**Newest helper, always:** https://github.com/makeithappenbsd-prog/btprint-helper/raw/latest/BTPrint-Setup.zip

Unzip it and run `Setup.cmd` as administrator, or let `Setup-NewBuyerPC.ps1 -BtPrint` do it.

Current version: 2.2.0 (TEST build on this branch). All label choices live in the menu at http://localhost:8765/setup on each computer: new size "Full page (Letter 8.5 x 11, regular printer)", copies (1-5), and leave phone / day / notes off the label. Re-running setup keeps these choices. 2.1.2 printed the קשר מ ☐ ד ☐ boxes as their own row under any item with סגירה. Each new version replaces `BTPrint-Setup.zip` on the `latest` branch, so the link above never changes.

Test link for 2.2.0 before it goes to `latest`: https://github.com/makeithappenbsd-prog/btprint-helper/raw/claude/project-thread-431y7f/BTPrint-Setup.zip
