# btprint-helper

Label printer helper for the Bedikas Tefilin app (Windows).

**Newest helper, always:** https://github.com/makeithappenbsd-prog/btprint-helper/raw/latest/BTPrint-Setup.zip

Unzip it and run `Setup.cmd` as administrator, or let `Setup-NewBuyerPC.ps1 -BtPrint` do it.

Current version: 2.1.2 (the קשר מ ☐ ד ☐ boxes print as their own row under any item with סגירה, not in the container box). 2.1.1 added the printer picker page at http://localhost:8765/setup. Each new version replaces `BTPrint-Setup.zip` on the `latest` branch, so the link above never changes.
